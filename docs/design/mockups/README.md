# Mockups (referensi visual)

Buka file `.html` di browser. Tiga file berikut berdiri sendiri dan **bisa digerakkan**:
- `prototype.html` — Login, Beranda, Form laporan (login ↔ daftar, tambah/hapus pasien, urungkan)
- `splash.html` — Splash v2 dengan garis waktu, 7 frame kunci, dan tabel spesifikasi gerak
- `status-prototype.html` — Offline/online, banner, sinkronisasi, pesan singkat, dialog

Folder `main-canvas/` dan `status-canvas/` berisi artboard statis (`*.dc.html`, 390 px lebar).
File itu perlu runtime kanvas untuk tampil, jadi **bacalah sebagai sumber**: ukuran, warna, teks, jarak, dan urutan elemen ada di markup-nya.
Peta layar ke mockup ada di `.agents/skills/puskesmas-redesign/SKILL.md`.
Jika mockup dan teks spesifikasi berbeda, mockup menang untuk tampilan, dan `AGENTS.md` menang untuk aturan.
